# NTPC Prep — Free Website

A static RRB NTPC practice website using only HTML, CSS and JavaScript.

## Run locally
Open `index.html` in a browser.

## Free hosting
### GitHub Pages
1. Create a GitHub account and a new public repository.
2. Upload `index.html`, `style.css`, and `app.js`.
3. Repository Settings → Pages → Deploy from branch → `main` → `/root`.
4. Save. GitHub will provide the live website URL.

### Cloudflare Pages
Create a Pages project, upload the three files, and deploy as a static site.

Progress is stored in the visitor's browser using localStorage. No server/database is required.
